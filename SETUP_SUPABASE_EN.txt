  2. Open supabase_fase1.sql (in the zip), copy ALL of it, paste, click RUN.

STEP 4 · CONNECT THE APP  (2 values go into config.js)

  4a · GET THE PROJECT URL
       Project Settings -> Data API  (left sidebar, under Configuration)
       Copy "Project URL". It looks like:
            https://abcdefghij.supabase.co
       No slash at the end.

  4b · GET THE KEY
       Project Settings -> API Keys
       Under "Publishable key", row "default", click the copy icon.
       It looks like:
            sb_publishable_4z755311D1gF3oLmlQhksw_yn10-...
       This is the PUBLIC key. It is meant to live in the app. It can only
       INSERT fuel POs and READ the catalogs. It CANNOT read the registry.
       (Verified: reading fuel_pos with this key returns 401.)

       *** DO NOT USE the "Secret key" (sb_secret_...). ***
       That one bypasses all security. It never goes in the app, never in
       GitHub. If it ever leaks, click the 3 dots next to it and roll it.

       If you prefer the older style key, the tab "Legacy anon, service_role
       API keys" has an "anon public" key starting with eyJ... That works too;
       the app accepts either.

  4c · PASTE THEM IN config.js
       Find this block near the top of config.js:

            SUPABASE: {
              URL:      "",
              ANON_KEY: "",
            },

       Make it look like this (your real values, keep the quotes and commas):

            SUPABASE: {
              URL:      "https://abcdefghij.supabase.co",
              ANON_KEY: "sb_publishable_4z755311D1gF3oLmlQhksw_yn10-...",
            },

  4d · UPLOAD TO GITHUB
       config.js, fuel.js, fuel.css, fuel.html, sw.js
       (fuel.js changed today to support the new key format - upload it.)

  HOW YOU KNOW IT WORKED: open fuel.html on your phone. Tap a name. If the
  vehicle list shows up, the app is talking to the database. If the app looks
  the same but a PO still asks you to send a text, the keys did not take -
  check for a missing quote or comma in config.js.

AFTER THAT · YOU OPERATE FROM SUPABASE (Table Editor), not config.js
  vehicles   -> ENTER THE PLATES (plate column). Once a plate is in, nobody
                can type one. Fix comb (DIESEL/GASOLINA) if any are wrong.
  jobsites   -> add/remove jobsites (locations, never contract numbers)
  roster     -> EVERY MONDAY: new rows (person, week_start = Monday, jobsite)
                from the 6-Week Lookahead. The app proposes that jobsite first.
  people     -> add/remove. active=false hides someone without deleting history.
  stations   -> Leo's phone number if they want the PO by text.
  fuel_pos   -> the registry. gallons/amount columns are for when the invoice
                arrives (Phase 4 will fill them automatically).
  fuel_pos_flagged (view) -> the red flags computed by the server.
